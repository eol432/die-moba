# 사감쌤 몰래 라면 먹기 - 모바일 버전 Render 서버

업로드한 dorm_ramen_9.html을 독립적으로 실행하는 Render 서버 프로젝트입니다.

## GitHub에 올리기
1. 이 ZIP 파일을 압축 해제합니다.
2. GitHub에서 새 저장소(repository)를 만듭니다.
3. 압축 해제한 폴더 안의 파일과 `public` 폴더를 저장소 최상위에 업로드합니다.
4. Render에서 **New + → Blueprint**를 선택합니다.
5. 방금 만든 GitHub 저장소를 연결하고 배포합니다.
6. 배포가 끝나면 Render가 제공한 주소로 게임에 접속합니다.

## 주의
- 이 프로젝트는 이 게임 파일만 포함한 별도 Render 서비스입니다.
- 온라인 방 연결을 위한 PeerJS 서버가 같은 Render 서비스에서 실행됩니다.
- 게임 방을 만든 브라우저가 방의 호스트 역할을 하므로, 호스트가 나가면 해당 방이 종료될 수 있습니다.
- 무료 Render 서비스는 일정 시간 요청이 없으면 잠들 수 있어 첫 접속 때 시작이 늦어질 수 있습니다.
